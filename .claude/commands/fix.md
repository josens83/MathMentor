# 버그 수정

체계적인 디버깅 프로세스를 따라 버그를 수정합니다.

## 버그 설명
$ARGUMENTS

## 디버깅 프로세스

### 1단계: 재현 (Reproduce)
- 버그 재현 단계 확인
- 관련 테스트 실행하여 실패 확인
- 에러 메시지 및 스택 트레이스 분석

### 2단계: 격리 (Isolate)
- 관련 코드 검색 (Grep/Glob)
- 문제 범위 좁히기
- 의심되는 코드 영역 식별

### 3단계: 분석 (Analyze)
- 근본 원인 파악
- 코드 플로우 추적
- 타입 및 데이터 검증

### 4단계: 수정 (Fix)
- 최소한의 변경으로 수정
- 회귀 방지 테스트 추가
- 타입 안전성 유지

### 5단계: 검증 (Verify)
```bash
npm run typecheck
npm run test
npm run lint
```

위 단계를 순서대로 진행하여 버그를 수정해주세요.
